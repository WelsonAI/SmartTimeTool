# Smart Time Tool

An interactive, textbook-aligned time learning tool for Malaysian primary pupils.

## Learning modes

- Read and set an analogue clock
- Follow a visual timeline to find a start time, end time, or duration
- Calculate time with addition, subtraction, multiplication, and division
- Use a calendar to identify weekdays and count dates
- Convert textbook-supported time units
- Compare world time zones and date changes
- Create teacher questions within each year's supported scope

The interface supports Bahasa Melayu, Chinese, and English, includes sound feedback, and uses the same child-friendly visual system as the other Smart Math tools.

## Textbook-aligned progression

- Year 2: five-minute intervals, analogue and digital time, simple start/end time, `1 hour = 60 minutes`, and `1 day = 24 hours`.
- Year 3: schedules, a visual second hand, calendars, time-unit relationships, and calculations with time durations.
- Year 4: 12-hour and 24-hour systems, elapsed time, and larger time units.
- Year 5: duration across dates and fractional or decimal time conversions.
- Year 6: world time zones, time differences, and date changes.

Only modes supported by the selected year's textbook are shown. The tool starts at Year 2 because the supplied textbook set starts at Year 2.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
